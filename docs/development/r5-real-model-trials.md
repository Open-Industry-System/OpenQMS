## 两份独立合成报告

全部公司、产品、数量和测量均为虚构；不声称代表现场调查结论。分别在试用租户创建报告和对应合成 FMEA 来源，使用平台正常 D4 校验形成真实的来源证明与当前根因版本，不手写 proof ID 或绕过验证。

**LOCAL：合成连接器压接接触不良。** 标题“R5 LOCAL 合成试用—连接器间歇开路”。D2：合成批次 SYN-L-001 的100件样品中8件振动后间歇开路。D3：隔离该合成批次，临时逐件测量接触电阻。D4：合成试验发现剥线刀磨损使部分线芯被切断，压接后有效导体截面积不足；现有检查仅看外观，未检查剥线后线芯完整性。合成对比：磨损刀具组8/100失效，新刀具组0/100，剖面检查与导体完整性一致。合成 FMEA 原因节点记录该原因及现行外观检查。请求模型依据当前 D4 提出可执行 D5 建议，并通过平台工具保存到当前报告。

**CLOUD：合成注塑壳体毛边。** 标题“R5 CLOUD 合成试用—壳体分型面毛边”。D2：合成批次 SYN-C-001 的200件壳体中12件存在影响装配的分型面毛边。D3：隔离该合成批次，临时检查分型面。D4：合成试验发现锁模力传感器零点漂移，显示值高于实际值；实际锁模力不足导致分型面打开，现有点检只记录显示值，未做独立校准核对。合成对比：校准前12/200出现毛边，校准后同工艺窗口0/200。合成 FMEA 原因节点记录该原因及现行显示值点检。请求模型依据当前 D4 提出可执行 D5 建议，并通过平台工具保存到当前报告。

## 员工执行与工程师评价

1. 执行员工打开对应报告侧栏，记录当前 D4 版本及有效来源证明，选择已批准的具体 LOCAL/CLOUD 部署，显式创建“仅根据当前根因”的新任务。核对任务绑定名称/版本后启动。
2. 观察实际“读取 D4 → 生成建议 → 保存到报告”过程。若模型要求补充，员工只提供合成材料；来源不完整、模型未调用保存或调用失败时，如实记录，不能人工补写一条建议冒充模型保存成功。
3. 记录报告/任务/部署版本/建议 ID、控制审计和业务保存回执、开始结束时间及固定失败码。不要把凭据、运行令牌或完整原始模型日志放进 PR。LOCAL/CLOUD 证据分别保存，不能相互代替。
4. 任务结束后由有资格的质量工程师从报告建议面板查看原文、来源与依据状态，判断是否对应实际合成根因、措施是否具体可执行、能否检验效果、是否有无依据的数值或标准引用。逐条写“可用 / 修改后可用 / 不可用”及理由，保留模型原文和最终措辞。
5. 需要验证采纳时，由工程师按正常流程进入 D5，修改措辞并逐条采纳；保留原文、最终文本、来源及操作者。不以 Agent 自评或自动采纳替代工程判断。来源/根因变化后旧建议不可采纳；权限不足的员工不能看到受限正文。

验收成功至少要求两类部署各自有真实模型请求、实际 D4 读取、报告保存回执和人工质量结论。链路成功但建议不可用，仍记录为质量未签收；缺端点、专用凭据或工程师时，对应项继续 PENDING。
