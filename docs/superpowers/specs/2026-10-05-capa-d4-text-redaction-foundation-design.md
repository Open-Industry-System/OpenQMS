## 2. 已选择方案与替代方案

采用**格式规则＋员工显式替换词、全体输出继续 restricted**。它能保留技术叙述供有权员工检查规则是否误遮盖/遗漏，同时不产生新的降敏或外发权限。

## 3. 分类、来源与访问语义

### 3.1 模块拥有的分类

全部正文输入、规则替换结果和预览都固定 `data_class="restricted"`、`projection="redaction_candidate"`、`declassification_status="not_approved"`、`external_delivery_allowed=false`。客户输入或插件不能选择这些字段，也不能把结果升级为 internal/masked。结果是内部候选，不注册成 DIRECT 插件能力，不生成 model/plugin 许可。

`source_status` 区分 `unverified` 与 `validated_reference`；验证的是可追溯引用，不是文字事实、商业机密消失或降敏批准。缺少 source_ref 的自填正文仍可按当前人工 CAPA 读取权限生成受限候选，但不推断其语义来源，不允许扩大可见范围。

### 3.2 服务器来源与外模块引用

所有字段标签由服务器生成，绑定实际租户/generation、报告 UUID、验证 UUID（若有）、固定字段名、源版本和规则版本。不接收客户端自报 owner、classification、digest、源对象或授权范围。

`source_ref` 已有写入时关联/节点校验，但读取时不得假设它仍有效或代表当前权限。非空引用必须严格为已支持的 `{fmea_id,cause_node_id}`，重新检查：关联等于当前报告 fmea_ref_id；实际 FMEA 存在，factory/product line 与当前报告一致；节点仍为 FailureCause；当前员工具有 FMEA VIEW 及对象行级范围。读取只获取引用验证所需的当前元数据/节点存在性，不返回 FMEA 正文、图内容或标题，不做跨模块名称检索。

损坏、失效或不可见的明确来源使**整份预览及版本检查拒绝**；响应不返回正文、字段摘要、命中数、来源 ID 或记录数量，避免只凭 CAPA 可见泄漏外模块信息。不能静默忽略引用后只标 CAPA 来源继续放行。

### 3.3 当前员工权限与事务

请求只使用普通用户 JWT，必须当前用户/角色启用、CAPA VIEW，并满足当前工厂/产品线范围。运行 JWT、安装 secret、客户端身份/租户/schema 参数不能使用本接口。前端权限只控制呈现，后端独立校验。

首次授权后，以已捕获 TenantBinding 在独立 `REPEATABLE READ READ ONLY` 快照中读取显式字段、完整源集和引用元数据；多租户不回退 public。完成处理后重新读取当前员工权限、报告坐标及明确来源权限/版本；快照与最终实际事实不一致则拒绝旧内容，不保存成功审计。源版本检查使用相同当前权限规则。复用已有 namespace、factory/product-line、当前角色读取和只读快照逻辑，不重新发明身份规则；共享当前访问逻辑若需要移动，只做本片必要的小范围抽取，并保留 R4a 调用的默认行为与完整回归。

## 4. 确定性规则与输入限制

### 4.1 固定规则 v1

首版匹配明确格式：邮箱、常见中国大陆手机号（含 +86 与常用分隔）、标明的电话号码、18位居民身份证格式、HTTP/HTTPS URL、Bearer/JWT 形态及明显凭据键值（password、secret、api_key、token 的键值形式）。它是风险提示/替换规则，不验证证件真实有效，也不宣称覆盖所有国际号码、姓名、商业机密或混淆编码。

每一完整命中替换成固定类别标记，例如 `[邮箱已遮盖]`、`[手机号已遮盖]`、`[URL已遮盖]`、`[凭据已遮盖]`、`[指定词已遮盖]`。不保留姓名/号码前缀，不把原始命中词放进结果元数据。按原始文本位置处理区间：显式替换词优先，随后凭据/URL，再邮箱/证件/电话；重叠区间合并，避免部分秘密保留或占位符被二次匹配。不归一化改写业务原文；可用 Unicode 的等价形式匹配，但返回与命中范围的映射必须正确，不能擅自把规格、单位或编号转换成不同文本。

规则对结构化原文不起作用时也不自动放行外发。预览输出作为纯文本渲染，不当 HTML、Markdown 或链接执行，不跟随文本中的 URL。保留未命中的技术叙述用于有权员工检查，明确显示“受限脱敏候选，可能仍含敏感内容”。

### 4.2 显式替换词

请求只接收 `replacement_terms: list[str]`：0–50项，每项1–100字符，去除首尾空白后不得为空；总 UTF-8 字节不超过8 KiB，严格字符串，拒绝重复规范项和控制字符。不支持任意正则、替换模板、路径或自定义输出文本。按字面匹配，不解释 `$`、反斜杠或正则元字符；较长词优先。同一字段内替换确定可复现。

替换词仅保存在请求/当前组件的内存，不能落入日志、审计、数据库、localStorage、sessionStorage 或浏览器共享状态；关闭/隐藏/注销/目标或身份变化时清空。请求体的其他字段均拒绝，不用替换词决定授权、来源或敏感等级。

### 4.3 源数据预算与失败关闭

同报告最多200条验证记录，单正文最多64 KiB UTF-8，总正文最多256 KiB，单条非空 source_ref 的 JSON UTF-8 不超过2 KiB且只能是既有两键规范形状。只读快照先计算有界数量/字节预算，再加载正文或引用JSON，避免先把无界正文和附件拉入内存。超限不截断、不分页成不完整预览，也不先返回部分字段；统一常量 `PREVIEW_SOURCE_LIMIT` 冲突响应。无权请求先拒绝，不泄漏数量或超限事实。

空/None正文返回固定缺省状态，不生成假内容；非预期数据库/解析故障不会返回半份候选或异常正文。客户端取消请求和服务器失败都不触发业务修改。

## 5. 接口、源版本与审计

### 5.1 默认关闭的员工接口

新增 `CAPA_D4_TEXT_PREVIEW_ENABLED=false`，不与 R4a 的安装/运行开关混为一体。关闭时，在租户解析、认证、body读取和数据库查询前，针对预览端点返回404；其他 CAPA 路径不受影响。

- `GET /api/capa/{report_id}/d4-text-preview/availability`：普通用户当前CAPA/对象权限通过后仅返回 enabled=true，不读取正文、不枚举验证/外模块来源；它不保证后续预览一定获准。前端用此接口发现入口，关闭404时没有正文请求。
- `POST /api/capa/{report_id}/d4-text-preview`：body 只有 replacement_terms；生成受限候选与一次成功审计。JSON请求体在解析前最多64 KiB，超过则返回常量413，不先分配无界输入。
- `GET /api/capa/{report_id}/d4-text-preview/version`：只返回当前不含正文的源版本及规则版本，用于员工预览失效判断，不产生成功预览审计，不接收替换词。

响应为固定只读DTO，含 report_id、rule_version、source_version、generated_at、expires_at（生成时起30秒）、上述固定分类/外发标记，及字段列表。每项仅含固定字段名、已获授权的 report/verification ID、redacted_text/空状态、source_status、当前引用标签和按类别的命中计数，不含原始命中词、原文或替换词。

源版本覆盖三个原始字段与完整验证集合的所有相关值、空状态、排序 ID、更新时刻、当前报告坐标和明确来源引用/元数据版本，以及租户/generation。使用服务器域分离的 HMAC-SHA256 生成不透明版本，不对外暴露短原文的无密钥指纹；`source_version` 不能代替授权。规则版本是服务器常量，不能由客户端指定。

错误使用稳定诊断：关闭404；未认证401；无权/来源不可见或失效403，不泄漏对象存在；不存在目标404；严格输入错误422使用新路由专属的内容安全校验错误映射，**不得采用会回显 input 的默认422详情**；该映射也涵盖非法 report_id 与未知字段，不改变其他模块的异常格式。原始请求超限413仅常量 `PREVIEW_INPUT_LIMIT`。源集合超限或读取期间版本/坐标变化409；非预期故障500常量。不得把 SQL、原文、替换词或异常详情填回响应。

### 5.2 安全审计及存储

预览是只读业务操作，唯一持久化是 `AuditLog`：动作 `PREVIEW_CAPA_D4_TEXT`、当前操作者、报告/factory、规则版本、源版本引用和成功标记。默认不存正文、脱敏文本、替换词/词摘要、命中原词或自由错误文本。并发最终授权/版本冲突时不写成功记录，服务与 API 的提交职责显式；提交失败不能返回候选成功。

不创建正文缓存、预览结果表、文件、embedding/outbox 或新的业务列；本片不需要数据库迁移。不会写验证结论/原文字段，也不采用通用 update 绕过状态机。

## 6. 人工只读预览界面

CAPA D4 区增加明确“正文脱敏候选预览”入口，与现有 AI 起草/替换/采纳按钮区分。禁用默认配置下不发正文请求；实际关闭/无权时隐藏入口并清除预览。组件不复用带 onReplace/onAppend 的 AIDraftPreview，不含保存、采纳、复制原文或发布/交付按钮。

只读弹窗包括：固定警示、显式替换词输入、生成候选、三个字段类型与受限文本/命中计数、来源状态/规则与源版本。纯文本展示，不执行HTML或链接；只为有权员工查看，不显示无权来源计数或ID。

弹窗打开且候选存在时，每2秒检查版本；30秒有效期截止无论网络是否在线都清空正文/计数。版本变更、规则版本变化、401/403/404、身份/租户/报告/工厂/产品线变化、关闭/隐藏、替换词修改均中止旧请求并清空结果。版本校验网络中断同样撤回正文，显示常量提示并允许显式重新生成；不把本地旧候选当作已确认最新，不在后台隐藏页轮询。新响应必须匹配发起时身份/目标/替换词请求轮次；过期或被取消的响应不得回填。

此轮询边界不宣称撤回已被员工看过/复制的信息，也不改变原有人工详情接口；它阻止新组件继续把失效候选当作当前授权结果。
