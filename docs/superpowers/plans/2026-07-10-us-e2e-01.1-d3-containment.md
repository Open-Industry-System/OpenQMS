# US-E2E-01.1 D3 遏制全链路 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 CAPA 8D 的 D3 阶段实现「数据导入 → 受影响范围分析报告 → AI 遏制建议 → 采纳/执行记录 → D3→D4 闸口」全链路（AI_REQUIRED=true，无 LLM 凭证 BLOCKED）。

**Architecture:** 7 张不可变 generation 表（import_run→report→advice_generation→advice + adoption + execution），三阶段 LLM 短事务（锁+建 running artifact+提交 → 无锁 LLM → 重锁+attempt_token CAS 晋升/失败），事实确定性计算 + LLM 只做风险分级与建议文本，D3→D4 闸口 fail-closed。详见 `docs/superpowers/specs/2026-07-10-us-e2e-01.1-d3-containment-design.md`（v15 定稿）——**本计划是任务分解，所有字段/CHECK/CAS/枚举契约以 spec 为唯一真源，实现时逐条对照 spec §3/§4/§5/§6**。

**Tech Stack:** Python 3.11 + FastAPI 0.115 (async) + SQLAlchemy 2.0 (async) + PostgreSQL 15 + Pydantic v2 + React 18 + TypeScript 5.6 + Playwright E2E

## Global Constraints

- `factory_id` NOT NULL 全表（7 表）+ 复合 FK 保证父子 factory 一致（spec §3 表头 + §14）
- 统一 ON DELETE RESTRICT + CAPA 软删除（归档不物理删）；存在 D3 审计实体禁止物理删 CAPA/run/report/generation（spec §3 表头）
- 不可变 generation 覆盖 run→report→advice_generation→advice；每层 `is_current` partial unique index + `status` running/done/failed 三态 + 综合 CHECK（spec §3.1/§3.3/§3.5）
- attempt_token CAS：所有 terminal transition（成功 + 所有失败分支）用 `WHERE id AND status='running' AND attempt_token=:token`，行数 0 丢弃（spec §4.2/§4.3 + §14）
- 原子晋升分步顺序：run 5 步、report 4 步、advice generation 5 步；CAS done/is_current 保持 false→旧 false→新 true+completed_at→回滚（spec §3.1/§3.3/§3.5 + §14）
- done 完整性 CHECK：report done 必含 5 项确定性结果 + risk_floor + risk_explanation 非空 + llm_available=true + completed_at；advice done 必 advice_count>0 + llm_available=true（spec §3.3/§3.5 + §14）
- 失败分支审计全覆盖：error code 枚举 `superseded`/`llm_failed`/`schema_failed`/`all_provenance_mapping_failed`/`unknown_risk_mapping_version`/`stale`，写 stage_runs（spec §3.5 + §4.2/§4.3）
- 快照固化分析数据：shipment payload 固化 unit/customer_segment/customer_name/arrival_status；run.analysis_context 固化 capa_severity + risk_mapping_version（唯一真源）；报告只读 payload + run.analysis_context 不查源表（spec §3.1/§3.2 + §4.2）
- RISK_MAPPINGS 版本注册表：服务层常量，旧版本不可删，未知版本→failed 不静默（spec §3.3 + §14）
- record_key 永不为空只有 snapshot_id 可空；batch_key=hash(normalized_material+normalized_lot)，lot 缺失退化 `{snapshot_type}:{source_id}`（spec §3.2/§3.4）
- IQC 查 `iqc_inspections` JOIN suppliers（非 iqc_materials 主数据）（spec §4.1）
- AI_REQUIRED=true：无凭证 BLOCKED（422 blocked 独立端点；import 端点 report_status=blocked）；建议生成先检查凭证再建 generation（spec §4.2/§4.3）
- 重复请求返 202 Accepted + 现有 running artifact ID + status + Retry-After header（秒）（spec §3.3/§3.5 + §7）
- 状态机：D3_INTERIM→D4_ROOT_CAUSE 线性边已在 `eightd_state.py`，无需改状态机；D3 阶段守卫 `capa.status == D3_INTERIM`（spec §5 + §14）
- 发布策略：A+B 原子发布（Slice A/B 仅实现顺序，不分阶段上线）（spec §2 + §14）
- 复用：`provider_adapter.complete_json` + `provider_adapter.build_client`/`ProviderNotConfiguredError`（01.2/01.3 已迁移）、`capa_draft_service` 的 MAX_PROMPT_CHARS=8000 截断 + safety_trailer + DB-backed timeout 口径、`backend/tests/migrations/` 迁移测试基础设施（01.2/A3 已建 `mig_db_url` fixture + `_cfg` helper）、`capa_verification_service` 的 AuditLog 写法
- seed 在 `backend/app/seed_e2e.py` + `backend/app/seed_e2e_constants.py`（**非** frontend/e2e 下）

**故障注入机制（E2E + 服务测试）：**
- **LLM 失败/超时/schema 错**：后端服务测试用 `llm_mock`/`llm_slow`/`llm_raise`/`llm_bad_schema` fixture（直接 mock `complete_json`）
- **无凭证**：`no_creds` fixture mock `build_client` 抛 `ProviderNotConfiguredError`
- **stale worker 复活**：`llm_slow` + `asyncio.Event`——A 请求先建 running（阶段①），`hold_a.set()` 前 B 请求把 A 标 stale→failed，再 `hold_a.set()` 释放 A 的阶段②③，断言 A CAS 行数 0 不晋升
- **改源表验证快照确定性**：import 后 `UPDATE customers SET segment='normal' WHERE ...`（直接 SQL）再重生成报告，断言报告 customer_impact 仍用快照固化值 'key'
- **E2E 故障注入**：E2E 只覆盖主流程 + 可通过 UI 触发的边界（无凭证 skip、跨工厂 404、scheme 422）。**LLM 失败/超时/stale/全过滤/并发竞争/改源表这些需精细 fixture 的场景，留在后端服务/集成测试**（`test_capa_d3_report.py`/`test_capa_d3_advice.py`），**不进 E2E**——E2E 的 Playwright 无法可靠控制 provider/暂停 worker/直接改 DB。E2E 反向组（Task 14）只保留 UI 可达场景，故障注入场景在后端测试任务内。
- **工厂切换**：`other_factory_client` fixture（不同工厂 token + 不同工厂 capa）

`capa_d3_containment_service.py`：5 个纯函数（spec §4.2 行 370-375 + §3.2 batch_key 规则）。
**P1-1 修复**：测试传 **dict**（`{"snapshot_type","snapshot_id","payload":[...]}`），payload 是 **list of dict**（非 ORM、非 dict payload）；batch_key=`hash(normalized_material + normalized_lot)`，lot 缺失退化 `{snapshot_type}:{source_id}`；`_compute_impact_qty` 返回 dict（按 status 数组汇总）；`_compute_time_window` 读 SPC alarm 的 `triggered_at`；`_compute_risk_floor` 读 **冻结的 `analysis_context.risk_mapping_version`**（非 CURRENT 常量），未知版本返 `(None, "unknown_risk_mapping_version")`。
```python
from hashlib import sha256
from app.services.capa_d3_risk_mappings import RISK_MAPPINGS

# 输入约定：snapshots 是 list[dict]，每项 {"snapshot_type","snapshot_id","payload":[record,...]}；
# 每个 record 是 dict（含 record_key/source_id/material_code/lot_no/quantity/unit 等）。

def _norm(v):
    return (v or "").strip().lower() if isinstance(v, str) else (str(v) if v is not None else "")

def _batch_key(material_code, lot_no, snapshot_type, source_id):
    """spec §3.2: hash(normalized_material + normalized_lot)；lot 缺失退化 {snapshot_type}:{source_id}"""
    m = _norm(material_code)
    lot = _norm(lot_no)
    if not lot:
        return f"{snapshot_type}:{source_id}"  # 退化（record_key 永不为空）
    raw = f"{m}|{lot}"
    return sha256(raw.encode()).hexdigest()[:16]

def _material_of(rec, snapshot_type):
    """统一物料标识：inventory/shipment 用 material_code；IQC 用 part_no（spec §4.1 IQC payload 契约字段）。
    P1-1 修复：IQC 的 part_no 与 inventory/shipment 的 material_code 同值时合并为同一 batch。"""
    if snapshot_type == "iqc":
        return rec.get("part_no", "")
    return rec.get("material_code", "")

def _compute_batches(snapshots: list[dict]) -> list[dict]:
    """按 (material, lot) 合并跨源批次；qty_by_status 只 inventory/shipment 贡献数量，IQC/SPC 进 source_refs 不进数量。
    P1-1 修复：IQC 用 part_no 作物料标识（与 material_code 同值合并）；shipment 按 arrival_status 分流
    （in_transit→in_transit，signed/unknown→shipped）；同源 source_id 去重；不同单位不混加（按 {qty,unit} 数组保留）。
    返回: [{"batch_key","material_code","lot_no","qty_by_status":{"inventory":[...],"shipped":[...],"in_transit":[...]},"source_refs":[...]}]
    """
    by_key: dict[str, dict] = {}
    for s in snapshots:
        st = s["snapshot_type"]; sid = s["snapshot_id"]
        seen_sources: set[str] = set()  # 同 snapshot 内按 source_id 去重
        for rec in s.get("payload", []):
            src_id = rec.get("source_id", rec.get("record_key", ""))
            if src_id in seen_sources:
                continue  # 去重不双计
            seen_sources.add(src_id)
            mat = _material_of(rec, st); lot = rec.get("lot_no")
            key = _batch_key(mat, lot, st, src_id)
            b = by_key.get(key)
            if b is None:
                b = {"batch_key": key, "material_code": mat, "lot_no": lot,
                     "qty_by_status": {"inventory": [], "shipped": [], "in_transit": []},
                     "source_refs": []}
                by_key[key] = b
            # 数量只 inventory/shipment 贡献；IQC/SPC 仅进 source_refs
            if st == "inventory":
                b["qty_by_status"]["inventory"].append({"qty": rec.get("quantity", 0), "unit": rec.get("unit", "pcs")})
            elif st == "shipment":
                # P1-1 修复：按 arrival_status 分流——in_transit→in_transit，signed/unknown→shipped
                status_field = "in_transit" if rec.get("arrival_status") == "in_transit" else "shipped"
                b["qty_by_status"][status_field].append({"qty": rec.get("quantity", 0), "unit": rec.get("unit", "pcs")})
            b["source_refs"].append({"snapshot_type": st, "snapshot_id": sid,
                                     "record_key": rec.get("record_key", src_id)})
    return list(by_key.values())

def _compute_impact_qty(batches: list[dict]) -> dict:
    """按 status 汇总数量；同 status+unit 求和合并，不同 unit 保持分组（spec §3.3 impact_qty 数组契约）。
    P1-1 修复：不再拼接原始数组——同单位累加 qty，不同单位各自一条 {qty,unit}。
    返回: {"inventory":[{"qty","unit"}],"shipped":[...],"in_transit":[...]}"""
    out: dict[str, list[dict]] = {"inventory": [], "shipped": [], "in_transit": []}
    for b in batches:
        for status, arr in b["qty_by_status"].items():
            bucket = out.setdefault(status, [])
            for q in arr:
                unit = q.get("unit", "pcs")
                # 找同 unit 累加
                existing = next((e for e in bucket if e["unit"] == unit), None)
                if existing is None:
                    bucket.append({"qty": q.get("qty", 0), "unit": unit})
                else:
                    existing["qty"] += q.get("qty", 0)
    return out

def _compute_customer_impact(shipment_snapshot: dict) -> list[dict]:
    """按客户聚合 shipment；客户名从快照固化（report 只读 payload，v8 F3）；quantities 为数组（不同单位不合并）。
    返回: [{"customer_name","customer_segment","arrival_status","quantities":[{"qty","unit"}]}]"""
    by_cust: dict[str, dict] = {}
    for rec in shipment_snapshot.get("payload", []):
        cust_code = rec.get("customer_code", "unknown")
        c = by_cust.get(cust_code)
        if c is None:
            c = {"customer_name": rec.get("customer_name", cust_code),
                 "customer_segment": rec.get("customer_segment", "normal"),
                 "arrival_status": rec.get("arrival_status", "unknown"),
                 "quantities": []}
            by_cust[cust_code] = c
        c["quantities"].append({"qty": rec.get("quantity", 0), "unit": rec.get("unit", "pcs")})
    return list(by_cust.values())

def _compute_time_window(spc_snapshot: dict) -> dict:
    """SPC alarm triggered_at 的 min~max（spec §4.2 时间窗口由 SPC 判异 alarm 确定性取最早~最晚）。
    返回: {"start","end}（无 alarm 数据返 {"start":None,"end":None}）"""
    times = [r.get("triggered_at") for r in spc_snapshot.get("payload", []) if r.get("triggered_at")]
    if not times:
        return {"start": None, "end": None}
    return {"start": min(times), "end": max(times)}

def _compute_risk_floor(customer_impact: list[dict], analysis_context: dict) -> tuple[str | None, str | None]:
    """若存在 arrival_status='unknown' 的受影响客户 → 'high'（保守）；
    否则用 analysis_context.capa_severity 按 analysis_context.risk_mapping_version（冻结）查 RISK_MAPPINGS。
    未知版本 → 返回 (None, "unknown_risk_mapping_version")（不静默用最新，v11 F1 P1）。
    返回: (floor, error_code)"""
    if any(ci.get("arrival_status") == "unknown" for ci in customer_impact):
        return ("high", None)
    version = analysis_context.get("risk_mapping_version")
    mapping = RISK_MAPPINGS.get(version)
    if mapping is None:
        return (None, "unknown_risk_mapping_version")  # 未知版本不静默
    severity = analysis_context.get("capa_severity", "general")
    floor = mapping.get(severity)
    return (floor, None)
```
> **说明**：`_compute_risk_floor` 读 `analysis_context`（run 冻结的 `{capa_severity, risk_mapping_version}`），而非 `CURRENT_RISK_MAPPING_VERSION` 常量——旧 run 重生成仍得原版本 floor（v11 F1）。`customer_impact` 与 `analysis_context` 由报告生成阶段②从快照 payload + run.analysis_context 读出后传入。

```python
import uuid
from datetime import datetime, timedelta
from sqlalchemy import select, update, text
from app.models.capa_d3 import (CapaD3ImportRun, CapaD3ContainmentSnapshot, CapaD3ImpactReport)
from app.models.audit import AuditLog
from app.services.agent import provider_adapter
from app.services.agent.provider_adapter import ProviderNotConfiguredError
from app.services.capa_d3_risk_mappings import RISK_MAPPINGS

REPORT_RESPONSE_SCHEMA = {
    "type": "object", "properties": {
        "risk_level": {"type": "string", "enum": ["high", "medium", "low"]},
        "risk_explanation": {"type": "string"},
    }, "required": ["risk_level", "risk_explanation"],
}
STALE_THRESHOLD = timedelta(seconds=60)  # started_at 超 2× LLM timeout 视为 stale
RETRY_AFTER_SECONDS = 2

# 阶段①：检查凭证 + 锁 capa + 重检 run.is_current + 建 report running + 提交（释放锁）
async def _report_phase1_create_running(db, run_id, user):
    # 先检查凭证（无凭证 BLOCKED，不建 running report，不破坏旧可用 report）
    try:
        client = await provider_adapter.build_client(db)
    except ProviderNotConfiguredError:
        return {"status": "blocked"}, None
    # 锁 capa 行（通过 run → capa）
    run = await db.get(CapaD3ImportRun, run_id)
    if run is None:
        return {"status": "failed", "error": "run_not_found"}, None
    await db.execute(text("SELECT 1 FROM capa_eightd WHERE report_id=:cid FOR UPDATE"), {"cid": run.capa_id})
    # 注意：run.is_current 在此仅记录，不在阶段①拒——superseded 检测在阶段③重检（run 可能被并发 import 取代）。
    # 但若 run 已非 current 且已有 current report，重复请求返 202 running；否则建 running report 让阶段③ CAS superseded。
    # stale 恢复：started_at 超阈的 running 先 CAS→failed
    await _recover_stale_report(db, run_id)
    # 重复请求：已有 running report → 202 Accepted + 现有 ID + Retry-After
    existing = await _running_report(db, run_id)
    if existing:
        return {"status": "running", "report_id": str(existing.report_id),
                "retry_after": RETRY_AFTER_SECONDS}, None
    attempt_token = uuid.uuid4()
    report = CapaD3ImpactReport(
        report_id=uuid.uuid4(), run_id=run_id, factory_id=run.factory_id,
        is_current=False, status="running", attempt_token=attempt_token,
        started_at=datetime.utcnow(), generated_by=user.user_id, stage_runs=[], prompt_stats={},
        llm_available=False, batches=[], impact_qty=[], customer_impact=[], time_window={},
    )
    db.add(report); await db.flush()
    await db.commit()  # 阶段①提交，释放 capa 锁
    return ({"status": "phase1_done", "report_id": report.report_id,
             "attempt_token": attempt_token, "run": run, "client": client}, None)

# 阶段②：读快照→转纯 dict→结束读事务→无事务 _compute_* + LLM（schema 校验 + schema_failed 分支）
async def _report_phase2_llm(db, report_id, run, client):
    # 读快照 payload + analysis_context → 转纯 dict/标量
    snapshots = (await db.execute(select(CapaD3ContainmentSnapshot).where(
        CapaD3ContainmentSnapshot.run_id == run.run_id))).scalars().all()
    snap_dicts = [{"snapshot_type": s.snapshot_type, "snapshot_id": str(s.snapshot_id),
                   "payload": s.payload} for s in snapshots]
    analysis_context = dict(run.analysis_context or {})
    # P0 修复：转纯值后 commit 结束读事务——LLM 期间不持 DB 事务/连接
    await db.commit()
    # 以下纯内存计算 + LLM，不触碰 DB
    ship_snap = next((d for d in snap_dicts if d["snapshot_type"] == "shipment"), {"payload": []})
    spc_snap = next((d for d in snap_dicts if d["snapshot_type"] == "spc"), {"payload": []})
    batches = _compute_batches(snap_dicts)
    impact_qty = _compute_impact_qty(batches)
    customer_impact = _compute_customer_impact(ship_snap)
    time_window = _compute_time_window(spc_snap)
    risk_floor, err_code = _compute_risk_floor(customer_impact, analysis_context)
    if err_code == "unknown_risk_mapping_version":
        return {"outcome": "unknown_risk_mapping_version", "error": err_code,
                "batches": batches, "impact_qty": impact_qty, "customer_impact": customer_impact,
                "time_window": time_window}
    prompt = _build_report_prompt(batches, impact_qty, customer_impact, time_window,
                                  analysis_context)  # 脱敏 customer_0X + 截断 + safety_trailer
    prompt_stats = {"truncated": len(prompt) > MAX_PROMPT_CHARS, "original_total": len(prompt)}
    if prompt_stats["truncated"]:
        prompt = prompt[:MAX_PROMPT_CHARS] + SAFETY_TRAILER
    try:
        llm_result = await provider_adapter.complete_json(client, prompt, REPORT_RESPONSE_SCHEMA)
    except Exception as e:
        return {"outcome": "llm_failed", "error": "llm_failed",
                "stage_runs": [{"stage": "llm", "error": str(e)}]}
    # P1-2 修复：schema 校验——dict + risk_level∈枚举 + risk_explanation 非空字符串
    # （空 risk_explanation 不应等 done CHECK 报 IntegrityError，应在阶段②判 schema_failed）
    RISK_ENUMS = {"high", "medium", "low"}
    if (not isinstance(llm_result, dict)
            or llm_result.get("risk_level") not in RISK_ENUMS
            or not isinstance(llm_result.get("risk_explanation"), str)
            or not llm_result.get("risk_explanation", "").strip()):
        return {"outcome": "schema_failed", "error": "schema_failed",
                "stage_runs": [{"stage": "schema", "error": "expected {risk_level∈{high,medium,low}, risk_explanation:non-empty str}"}]}
    llm_risk = llm_result.get("risk_level", "medium")
    # P1-2 修复：从 customer_impact 构造 alias→真名 映射，还原 LLM 输出中的 customer_0X 代号
    _ci_alias_map = {f"customer_{idx:02d}": ci["customer_name"]
                     for idx, ci in enumerate(customer_impact, start=1)
                     if isinstance(ci, dict) and ci.get("customer_name")}
    explanation = _restore_customer_names(llm_result.get("risk_explanation", ""), _ci_alias_map)
    risk_level = _max_risk(llm_risk, risk_floor)  # max(llm, floor)
    return {"outcome": "ok", "batches": batches, "impact_qty": impact_qty,
            "customer_impact": customer_impact, "time_window": time_window,
            "risk_floor": risk_floor, "risk_level": risk_level,
            "risk_explanation": explanation, "prompt_stats": prompt_stats, "llm_result": llm_result}

# 阶段③：重锁 + CAS done/failed/superseded（4 步晋升，attempt_token CAS 行数 0 丢弃）
# 成功/失败/superseded 都写 AuditLog（spec §8）；P1-3 修复：terminal transition + 审计同一事务原子提交
async def _report_phase3_cas(db, capa_id, run_id, report_id, attempt_token, phase2, user):
    model = phase2.get("model", "unknown")
    await db.execute(text("SELECT 1 FROM capa_eightd WHERE report_id=:cid FOR UPDATE"), {"cid": capa_id})

    def _audit(fields):
        db.add(AuditLog(table_name="capa_eightd", record_id=capa_id, action="D3_REPORT_GENERATED",
                        changed_fields=fields, operated_by=user.user_id, operated_at=datetime.utcnow()))

    # 重检 run.is_current：被并发 import 取代 → CAS superseded（spec §4.2 阶段③ superseded 分支）
    run = await db.get(CapaD3ImportRun, run_id)
    if run is None or not run.is_current:
        res = await db.execute(update(CapaD3ImpactReport).where(
            CapaD3ImpactReport.report_id == report_id,
            CapaD3ImpactReport.status == "running",
            CapaD3ImpactReport.attempt_token == attempt_token
        ).values(status="failed", error="superseded", completed_at=datetime.utcnow(),
                 stage_runs=[{"stage": "phase3", "error": "run superseded"}]))
        if res.rowcount == 0:
            await db.commit(); return {"status": "superseded"}  # stale worker，无审计
        _audit({"report_id": str(report_id), "status": "failed", "error": "superseded"})
        await db.commit()  # CAS + 审计同一事务原子提交
        return {"status": "superseded", "report_id": str(report_id)}

    if phase2["outcome"] == "unknown_risk_mapping_version":
        res = await db.execute(update(CapaD3ImpactReport).where(
            CapaD3ImpactReport.report_id == report_id,
            CapaD3ImpactReport.status == "running",
            CapaD3ImpactReport.attempt_token == attempt_token
        ).values(status="failed", error="unknown_risk_mapping_version", completed_at=datetime.utcnow(),
                 stage_runs=[{"stage": "risk_floor", "error": "unknown_risk_mapping_version"}],
                 batches=phase2["batches"], impact_qty=phase2["impact_qty"],
                 customer_impact=phase2["customer_impact"], time_window=phase2["time_window"]))
        if res.rowcount == 0:
            await db.commit(); return {"status": "superseded"}
        _audit({"report_id": str(report_id), "status": "failed", "error": "unknown_risk_mapping_version"})
        await db.commit()
        return {"status": "failed", "report_id": str(report_id), "error": "unknown_risk_mapping_version"}

    if phase2["outcome"] == "llm_failed":
        res = await db.execute(update(CapaD3ImpactReport).where(
            CapaD3ImpactReport.report_id == report_id,
            CapaD3ImpactReport.status == "running",
            CapaD3ImpactReport.attempt_token == attempt_token
        ).values(status="failed", error="llm_failed", completed_at=datetime.utcnow(),
                 stage_runs=phase2["stage_runs"]))
        if res.rowcount == 0:
            await db.commit(); return {"status": "superseded"}
        _audit({"report_id": str(report_id), "status": "failed", "error": "llm_failed"})
        await db.commit()
        return {"status": "failed", "report_id": str(report_id), "error": "llm_failed"}

    if phase2["outcome"] == "schema_failed":
        res = await db.execute(update(CapaD3ImpactReport).where(
            CapaD3ImpactReport.report_id == report_id,
            CapaD3ImpactReport.status == "running",
            CapaD3ImpactReport.attempt_token == attempt_token
        ).values(status="failed", error="schema_failed", completed_at=datetime.utcnow(),
                 stage_runs=phase2["stage_runs"]))
        if res.rowcount == 0:
            await db.commit(); return {"status": "superseded"}
        _audit({"report_id": str(report_id), "status": "failed", "error": "schema_failed"})
        await db.commit()
        return {"status": "failed", "report_id": str(report_id), "error": "schema_failed"}

    # 成功 4 步晋升：① CAS running→done（is_current 保持 false）→ 行数 0 丢弃
    res = await db.execute(update(CapaD3ImpactReport).where(
        CapaD3ImpactReport.report_id == report_id,
        CapaD3ImpactReport.status == "running",
        CapaD3ImpactReport.attempt_token == attempt_token
    ).values(status="done", completed_at=datetime.utcnow(), llm_available=True, model=model,
             stage_runs=[], prompt_stats=phase2["prompt_stats"],
             batches=phase2["batches"], impact_qty=phase2["impact_qty"],
             customer_impact=phase2["customer_impact"], time_window=phase2["time_window"],
             risk_level=phase2["risk_level"], risk_floor=phase2["risk_floor"],
             risk_explanation=phase2["risk_explanation"]))
    if res.rowcount == 0:
        await db.commit(); return {"status": "superseded"}  # stale worker，丢弃
    # ② 旧 current → is_current=false
    await db.execute(update(CapaD3ImpactReport).where(
        CapaD3ImpactReport.run_id == run_id,
        CapaD3ImpactReport.report_id != report_id,
        CapaD3ImpactReport.is_current == True
    ).values(is_current=False))
    # ③ 新 → is_current=true
    await db.execute(update(CapaD3ImpactReport).where(
        CapaD3ImpactReport.report_id == report_id
    ).values(is_current=True))
    _audit({"report_id": str(report_id), "status": "done", "risk_level": phase2["risk_level"]})
    await db.commit()  # ④ 任一步失败整笔回滚（CAS + 晋升 + 审计原子提交）
    return {"status": "done", "report_id": str(report_id)}

async def generate_impact_report(db, run_id, user):
    """三阶段：①锁 capa + 检查凭证 + 建 report running + 提交；
    ②无锁读快照→转纯 dict→commit→无事务 _compute_* + LLM；③重锁 + attempt_token CAS done/failed/superseded"""
    p1, _ = await _report_phase1_create_running(db, run_id, user)
    if p1["status"] in ("blocked", "failed", "running"):
        return p1  # blocked / run_not_found / running(202)；superseded 在阶段③处理
    report_id = p1["report_id"]; attempt_token = p1["attempt_token"]
    run = p1["run"]; client = p1["client"]
    phase2 = await _report_phase2_llm(db, report_id, run, client)
    phase2["model"] = getattr(client, "model", "unknown")  # P0 修复：model 经 phase2 传入 phase3
    return await _report_phase3_cas(db, run.capa_id, run_id, report_id, attempt_token, phase2, user)

async def _running_report(db, run_id):
    return await db.scalar(select(CapaD3ImpactReport).where(
        CapaD3ImpactReport.run_id == run_id, CapaD3ImpactReport.status == "running"))

async def _recover_stale_report(db, run_id):
    """started_at 超阈的 running → CAS running→failed（error='stale'）。
    P0 修复：按 run_id+status+started_at 精确定位孤儿 running 行——running partial UQ 保证每 run 至多一行 running，
    不会误标并发 worker 的活跃行（其 started_at 新鲜，远低于阈值）。不按 status+时间批量跨 run 更新。
    阈值用 2× STALE_THRESHOLD 留余量，避免误标刚启动的合法 worker。"""
    stale_runs = [{"stage": "stale_recovery", "error": "started_at exceeded 2x threshold"}]
    await db.execute(update(CapaD3ImpactReport).where(
        CapaD3ImpactReport.run_id == run_id,
        CapaD3ImpactReport.status == "running",
        CapaD3ImpactReport.started_at < datetime.utcnow() - (STALE_THRESHOLD * 2)
    ).values(status="failed", error="stale", completed_at=datetime.utcnow(), stage_runs=stale_runs))

def _max_risk(llm_risk, floor):
    order = {"low": 0, "medium": 1, "high": 2}
    if floor and order.get(floor, 0) > order.get(llm_risk, 0):
        return floor
    return llm_risk
```

```python
async def generate_advice(db, capa_id, report_id, user, req: D3AdviceRequest):
    """三阶段：①锁 capa + 检查凭证 + 建 generation running + 提交；
    ②无锁 LLM + schema/provenance 映射；③重锁 + attempt_token CAS done/failed（5 步晋升）"""
    p1, _ = await _advice_phase1_create_running(db, capa_id, report_id, user)
    if p1["status"] in ("blocked", "failed", "running"):
        return p1  # 重复请求返 202 running / blocked / report_not_done
    gen_id = uuid.UUID(p1["generation_id"]); attempt_token = p1["attempt_token"]
    report = p1["report"]; client = p1["client"]
    # 阶段②无锁（读→转纯 dict→commit→无事务 LLM）
    phase2 = await _advice_phase2_llm(db, gen_id, report, report_id, client)
    # 阶段③重锁 CAS（phase2 已含 model/gen_factory_id，不需 client）
    return await _advice_phase3_cas(db, capa_id, report_id, gen_id, attempt_token, phase2, user)

def _map_provenance(advice_type: str, target_batch_refs: list[str] | None, report_batches: list[dict], snapshots: list[dict], report_id: str) -> list[dict]:
    """P1-1 修复：命中记录级追溯（spec §4.3 行 400-404）。
    - recall/notify_customer → shipment；isolate → inventory；strict_inspection → iqc；alternative → report
    - recall/notify_customer 反查 target_batch_refs 命中的 shipment 记录：从 batch.source_refs 找 source_type=shipment
      的真实 record_key，再验证该 record_key 存在于 shipment snapshot payload。
    - isolate/strict_inspection：取对应 snapshot_type 的真实记录 record_key（target_batch_refs 可为空，追溯该源全量证据）。
    - alternative → report summary（不依赖 snapshot）。
    无命中 → 返回空列表（该建议进 rejected，all_provenance_mapping_failed 可达）；不合成 record_key。
    record_key 永不为空字符串。"""
    SNAPSHOT_FOR = {
        "recall": "shipment", "notify_customer": "shipment",
        "isolate": "inventory", "strict_inspection": "iqc",
    }
    snap_type = SNAPSHOT_FOR.get(advice_type)
    if snap_type is None:
        # alternative → report summary provenance（不依赖 snapshot）
        return [{"source_type": "report", "snapshot_id": None,
                 "record_key": f"report:{report_id}:summary", "stage": "llm_advice"}]
    # 找对应 snapshot_type + 其 payload 中真实存在的 record_key 集合
    snap = next((s for s in snapshots if s["snapshot_type"] == snap_type), None)
    if snap is None or not snap.get("payload"):
        return []  # 找不到真实 snapshot → 空，过滤该建议
    sid = snap["snapshot_id"]
    valid_record_keys = {rec.get("record_key") for rec in snap["payload"] if rec.get("record_key")}
    if not valid_record_keys:
        return []  # payload 无有效 record_key → 空

    if advice_type in ("recall", "notify_customer"):
        # 反查 target_batch_refs 命中的 shipment 记录：从 report_batches 的 source_refs 找 shipment record_key
        if not target_batch_refs:
            return []  # recall/notify_customer 必须有 target_batch_refs 才能批次级追溯
        hit_keys: list[str] = []
        for b in report_batches:
            if b.get("batch_key") in target_batch_refs:
                for ref in b.get("source_refs", []):
                    if ref.get("snapshot_type") == snap_type and ref.get("record_key") in valid_record_keys:
                        rk = ref["record_key"]
                        if rk not in hit_keys:
                            hit_keys.append(rk)
        if not hit_keys:
            return []  # target_batch_refs 命中的 batch 无 shipment 记录 → 空，过滤
        return [{"source_type": snap_type, "snapshot_id": sid,
                 "record_key": rk, "stage": "llm_advice"} for rk in hit_keys]
    # isolate/strict_inspection：追溯该源全量证据（target_batch_refs 可为空）
    return [{"source_type": snap_type, "snapshot_id": sid,
             "record_key": rk, "stage": "llm_advice"} for rk in valid_record_keys]
```
> `_build_advice_prompt(report_batches, snapshots, name_to_alias)` / `_restore_customer_names(text, customer_alias_map)` 接收纯值（dict 列表 + 映射），不依赖 ORM 对象。`_build_advice_prompt` 用 `report_batches` 的确定性事实（material/lot/qty_by_status 摘要）+ 按 `name_to_alias`（真名→代号）脱敏 customer_0X + 截断 + safety_trailer。`_restore_customer_names` 按 `customer_alias_map`（代号→真名）把 LLM 输出中的 `customer_0X` 还原为真名。report 阶段②同样从 `customer_impact` 构造 `_ci_alias_map` 还原 `risk_explanation`（report 的 risk_explanation 不脱敏还原方向相同）。LLM 的 `provenance_sources_hint` 字段在 prompt 中可作辅助上下文，但**后端 provenance 映射按 advice_type + target_batch_refs 命中记录级追溯**（spec §4.3：后端确定性标注，非 LLM 自报）。

```python
async def adopt_advice(db, capa_id, advice_id, decision, adopted_text, user):
    # 链路归属校验：advice→generation→report→run→capa（P1-2 修复）
    advice = await db.get(CapaD3AiAdvice, advice_id)
    if advice is None: raise LookupError("建议不存在")
    gen = await db.get(CapaD3AdviceGeneration, advice.generation_id)
    if gen is None: raise LookupError("建议 generation 不存在")
    report = await db.get(CapaD3ImpactReport, gen.report_id)
    if report is None: raise LookupError("报告不存在")
    run = await db.get(CapaD3ImportRun, report.run_id)
    if run is None or run.capa_id != capa_id: raise LookupError("建议不属于该 CAPA")  # 链路终点
    # factory 一致性
    capa_factory = await _capa_factory(db, capa_id)
    if advice.factory_id != capa_factory: raise LookupError("建议跨工厂")
    # generation 校验
    current_gen = await _current_advice_generation(db, report.report_id)
    if advice.generation_id != current_gen.generation_id: raise ValueError("建议不属于当前 generation")
    existing = await db.scalar(select(CapaD3AdviceAdoption).where(CapaD3AdviceAdoption.advice_id==advice_id))
    if existing is None:
        adoption = CapaD3AdviceAdoption(advice_id=advice_id, factory_id=advice.factory_id, decision=decision, adopted_text=adopted_text, advice_type=advice.advice_type, source_provenance=advice.source_provenance, decided_by=user.user_id, decided_at=datetime.utcnow())
        db.add(adoption)
        db.add(AuditLog(table_name="capa_eightd", record_id=capa_id, action="D3_ADVICE_ADOPTED" if decision=="adopted" else "D3_ADVICE_REJECTED", changed_fields={"advice_id":str(advice_id),"decision":decision,"adopted_text":adopted_text}, operated_by=user.user_id, operated_at=datetime.utcnow()))
        await db.flush()
        return {"adoption_id": str(adoption.adoption_id)}
    elif existing.decision==decision and existing.adopted_text==adopted_text:
        return {"adoption_id": str(existing.adoption_id)}  # 幂等
    else:
        old_decision, old_text = existing.decision, existing.adopted_text
        existing.decision, existing.adopted_text, existing.decided_by, existing.decided_at = decision, adopted_text, user.user_id, datetime.utcnow()
        db.add(AuditLog(table_name="capa_eightd", record_id=capa_id, action="D3_ADVICE_DECISION_CHANGED", changed_fields={"advice_id":str(advice_id),"old_decision":old_decision,"new_decision":decision,"old_adopted_text":old_text,"new_adopted_text":adopted_text}, operated_by=user.user_id, operated_at=datetime.utcnow()))
        await db.flush()
        return {"adoption_id": str(existing.adoption_id)}
```

```python
def _validate_evidence_refs(refs):
    """P1-5 修复：允许 https://、/relative、./relative；拒绝 //、javascript:、file:、data:"""
    if len(refs) > 10: raise ValueError("证据最多 10 条")
    for r in refs:
        if len(r.get("name","")) > 200 or len(r.get("url","")) > 500: raise ValueError("name≤200/url≤500")
        url = r.get("url", "")
        # 拒绝危险 scheme
        if url.startswith(("javascript:", "file:", "data:")):
            raise ValueError("非法 url scheme")
        # 拒绝协议相对 URL（//evil.example）
        if url.startswith("//"):
            raise ValueError("非法 url scheme: protocol-relative not allowed")
        # 允许 https://、绝对路径 /、相对路径 ./
        if not (url.startswith("https://") or (url.startswith("/") and not url.startswith("//")) or url.startswith("./")):
            raise ValueError("非法 url scheme: 仅允许 https://、/path、./path")
```
