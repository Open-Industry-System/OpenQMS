# US-E2E-01.8: 8D → 知识库沉淀 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** D8 关闭时 fail-closed 沉淀结构化 `knowledge_entries`（LLM 摘要必填），异步向量化后可被产品检索与 stage-5 推荐命中，并写 `KNOWLEDGE_SUNK` / `KNOWLEDGE_RETRIEVED` 审计。

**Architecture:** 通用表 `knowledge_entries`（本轮仅 `source_type=capa`）+ `knowledge_sink_service.sink_capa_on_close` 挂在 `D8_APPROVAL_PENDING→D8_CLOSURE`。确定性 7 块字段服务层拼装；LLM 只产 `lesson_summary`+`tags`。无凭证 → `KnowledgeSinkBlockedError`（422 `outcome=blocked`）；LLM 失败 → `KnowledgeSinkFailedError`（422 `outcome=failed`）。Outbox 扩 `content_hash`，worker 防陈旧 processing 覆盖。`KnowledgeEntrySource` 作 stage 5 extra；审计失败 raise `KnowledgeAuditError` 并由 orchestrator re-raise。

**Tech Stack:** Python 3.11 + FastAPI + SQLAlchemy 2.0 async + PostgreSQL 15 + Alembic + pgvector | React 18 + TypeScript 5.6 + Ant Design 5 | Pytest async | Playwright E2E
