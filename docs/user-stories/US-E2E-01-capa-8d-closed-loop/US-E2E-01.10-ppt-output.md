# 子故事 US-E2E-01.10：8D 报告 PPT 输出

**状态**: 评审稿 v1（2026-07-08）
**所属 epic**: US-E2E-01（README.md v8.1）
**关联 skill**: `verify-capa-8d-ppt-output`
**前置**: 01.1-01.9（完整 8D 报告 + 联动 + 沉淀就绪，方有完整 PPT 内容）
**AI_REQUIRED**: false（PPT 生成是模板渲染，非 AI 步骤；功能错误 → `FAILED`）

## 故事

**作为** 现场质量工程师 / 8D 团队负责人，**我想** 在 8D 报告完成后（D8 关闭后或任意已完成阶段），
能**一键生成 8D 报告的 PPT 版本**（标准 8D 模板，用于汇报/归档/跨部门共享），可重复生成取最新数据，
**以便** 8D 报告可便捷输出为标准格式，便于汇报与归档。

## 背景 / 前置条件

- 系统已部署，8D 已完成 D8 关闭（01.1-01.9 全部交付，完整报告数据落库）。
- 系统后端可生成文件供前端下载。

## 能力：8D 报告 PPT 自动化输出

D8 关闭后（或报告任意已完成阶段），可**一键生成 8D 报告 PPT 版本**：

- **PPT 结构**（标准 8D 报告模板）：
  - 封面（8D 单号、标题、严重度、产品、发起人、状态、日期）
  - D1 团队
  - D2 问题描述
  - D3 遏制措施（含受影响范围摘要）
  - D4 根因分析（含验证记录摘要）
  - D5 永久措施
  - D6 实施验证
  - D7 预防复发（含 node-action 摘要）
  - D8 关闭结论
  - 联动关联附录（FMEA/SCAR/供应商风险）
- **生成方式**：后端生成 PPT 文件，前端下载；内容来自 8D 各步落库数据 + 证据附件引用。
- **可重复生成**：8D 数据变更后可重新生成（取最新落库数据）。

## 主流程

1. field_qe 或 8D 团队负责人在 8D 详情触发【生成 PPT】。
2. 系统从落库数据生成 8D 报告 PPT（D1-D8 + 封面 + 联动附录）。
3. 前端下载 PPT 文件。
4. 可重复生成（数据变更后取最新）。
5. 生成记录写审计日志。

## 业务规则 / 验收标准

- **一键生成**：D8 关闭后（或报告已完成阶段）可一键生成 PPT。
- **PPT 结构**：覆盖 D1-D8 各页 + 封面 + 联动附录，内容来自落库数据。
- **生成成功**：生成成功且可下载（文件非空、可打开）。
- **可重复生成**：可重新生成，取最新落库数据。
- **审计**：生成记录写审计日志（时间、生成人、版本）。
- **数据落库**：PPT 生成记录正确持久化。
- **执行验证**：E2E 断言 PPT 生成（文件可下载、结构完整、内容来自落库数据）。

## 验收契约（字段级）

| 项 | 定义 |
|---|---|
| 落库实体 | `capa_ppt_export`（生成记录） |
| 关键字段 | export.capa_id、export.generated_at、export.generated_by、export.version、export.file_url；PPT 结构页 D1-D8 + 封面 + 联动附录 |
| 状态枚举 | export 无状态（生成即成功）；文件存在且可打开 |
| 审计事件 | `PPT_GENERATED`（含 capa_id、generated_by、version） |
| E2E seed 前置 | 8D 完成 D8 关闭；各步数据落库 |
| 通过条件 | 一键生成 + D1-D8+封面+附录齐全 + 文件非空可下载 + 可重复生成 + 审计 |
| 失败条件（FAILED） | 生成失败；文件空/不可打开；结构缺页；内容非来自落库数据；未审计 |
| 阻塞条件（BLOCKED） | 无（AI_REQUIRED=false） |
