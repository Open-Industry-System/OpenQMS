# 子故事 US-E2E-01.5：8D 知识沉淀 + 横向扩散预警 + 报告输出

**状态**: 定稿 v1（2026-07-08）
**所属 epic**: US-E2E-01（README.md v8）
**关联 skill**: `verify-capa-8d-knowledge-output`
**前置**: 01.1、01.2、01.3、01.4、01.6（完整 8D 报告 + 联动 + 文档门禁就绪）

## 故事

**作为** 现场质量工程师 / 8D 团队负责人，**我想** 在 8D 报告完成（D8 关闭）后，
系统自动把 8D 报告数据**沉淀到对应产品知识库**（供后续产品开发设计调用参考），
并**检查是否有类似产品**可能受同一根因/失效模式影响，有则提示是否**通知相关产品负责人更新**，
且能**一键生成 8D 报告 PPT 版本**（用于汇报/归档/跨部门共享），
**以便** 8D 经验不流失、可被未来设计复用、同类风险能横向扩散预防、报告可便捷输出。

## 背景 / 前置条件

- 系统已部署，8D 已完成 D8 关闭（01.1-01.4 + 01.6 全部交付）。
- 对应产品已有知识库（pgvector 语义检索，01.2 全局知识库 RAG 源已就绪）。
- 产品主数据含 `product_types`（01.2 同类型产品推荐源已用）；FMEA 图、控制计划、供应商/物料数据可用。
- AI 步骤必须配置 `.env.e2e` 的 LLM 凭证（知识库沉淀的摘要/标签生成可能用 LLM）。

## 能力 A：8D 报告数据入知识库

D8 关闭时，系统自动把 8D 报告数据**结构化沉淀**到对应产品的知识库：

- **沉淀内容**（结构化知识条目，非纯文本）：
  - 8D 单号、标题、严重度、产品/产品线
  - D2 问题描述（现象）
  - D4 确认根因（含验证记录摘要）
  - D5 永久措施
  - D3 遏制措施（含受影响范围摘要）
  - D7 预防 node-action（含 FMEA 节点引用）
  - 8D 联动关联（FMEA/SCAR/供应商风险）
  - 关闭结论与经验教训摘要
- **可检索**：沉淀的知识条目进入 01.2 的"经验教训库检索"与"全局知识库 RAG"源，
  未来 8D/FMEA 触发推荐时可被检索命中（形成"当前 8D → 知识库 → 未来 8D"闭环）。
- **可调用参考**：后续产品开发设计时，可通过产品/产品线检索到该产品的历史 8D 经验。

## 能力 B：横向扩散预警

D8 关闭后，系统自动检查是否有**类似产品**可能受同一根因/失效模式影响：

- **类似产品判定**（4 个依据，取并集）：
  1. 同 `product_type`（产品主数据）
  2. 共享相同 FMEA 失效模式/根因（FMEA 图有相同或相似 FailureMode/Cause）
  3. 共享相同控制计划特性/控制参数
  4. 同供应商 + 同物料（同一供应商供的同一物料用于多个产品）
- **预警输出**：类似产品清单 + 每项的命中依据 + 建议更新方向。
- **通知动作**：系统弹出提示，询问是否通知相关产品负责人去更新产品内容；
  - 确认通知 → 生成通知（含本 8D 摘要 + 命中依据 + 建议更新方向）→ 发送给相关产品负责人；
  - 不通知 → 记录"已评估、不通知"及理由（留痕，不跳过评估）；
  - 通知状态可追踪（已通知/待通知/已处理）。

## 能力 C：8D 报告 PPT 自动化输出

D8 关闭后（或报告任意已完成阶段），可**一键生成 8D 报告 PPT 版本**：

- **PPT 结构**（标准 8D 报告模板）：
  - 封面（8D 单号、标题、严重度、产品、发起人、状态、日期）
  - D1 团队
  - D2 问题描述
  - D3 遏制措施（含受影响范围摘要）
  - D4 根因分析（含验证记录摘要）
  - D5 永久措施
  - D6 实施验证
  - D7 预防复发（含 node-action 摘要）
  - D8 关闭结论
  - 联动关联附录（FMEA/SCAR/供应商风险）
- **生成方式**：后端生成 PPT 文件，前端下载；含 8D 各步落库数据 + 证据附件引用。
- **可重复生成**：8D 数据变更后可重新生成（取最新落库数据）。

## 主流程

1. 8D 团队负责人审批 D7→D8_CLOSURE 关闭（01.3 审批流 + 01.6 门禁通过）。
2. D8 关闭时，系统自动触发知识库沉淀（能力 A）：8D 报告数据 → 结构化知识条目 → 对应产品知识库。
3. 沉淀完成后，知识条目可被未来 8D/FMEA 推荐检索命中（闭环）。
4. D8 关闭后，系统自动触发横向扩散检查（能力 B）：
   - 有类似产品 → 弹出提示，询问是否通知相关产品负责人；
   - 工程师/负责人确认通知 → 生成通知发送；不通知 → 记录理由。
5. field_qe 或 8D 团队负责人在 8D 详情触发【生成 PPT】（能力 C），系统生成 8D 报告 PPT 并下载。
6. 可重复生成（数据变更后取最新）。
7. 沉淀 + 横向扩散 + PPT 生成记录写审计日志。

## 业务规则 / 验收标准

- **知识库沉淀（能力 A）**：
  - D8 关闭时自动触发沉淀，无需人工干预（也可手动重新触发）；
  - 沉淀为结构化知识条目（含上述字段），非纯文本；
  - 沉淀后可被 01.2 的经验教训库/全局知识库检索源命中（E2E 验证：新发 8D 触发推荐时能命中本条沉淀）；
  - 后续产品设计可按产品/产品线检索到历史 8D 经验；
  - 沉淀记录写审计日志。
- **横向扩散预警（能力 B）**：
  - D8 关闭后自动触发类似产品检查，4 个判定依据取并集；
  - 有类似产品时弹出提示询问是否通知；确认通知则发送含 8D 摘要+命中依据+建议方向的通知；不通知需记录理由（不跳过评估）；
  - 通知状态可追踪（已通知/待通知/已处理）；
  - 检查结果 + 通知决策写审计日志。
- **PPT 输出（能力 C）**：
  - D8 关闭后（或报告已完成阶段）可一键生成 PPT；
  - PPT 覆盖 D1-D8 各页 + 封面 + 联动附录，内容来自落库数据；
  - 生成成功且可下载（文件非空、可打开）；
  - 可重复生成，取最新落库数据；
  - 生成记录写审计日志。
- **数据落库**：知识库沉淀条目（结构化）、横向扩散检查结果、通知记录（含状态）、PPT 生成记录正确持久化。
- **执行验证**：E2E 断言沉淀闭环（8D 关闭 → 知识库 → 新 8D 推荐命中）+ 横向扩散检查（类似产品识别 + 通知提示 + 通知/不通知留痕）+ PPT 生成（文件可下载）。
